## Reglas para Commits de Git
- NUNCA ejecutes comandos de `git commit` en la terminal.
- Cuando se te pida generar un mensaje de commit, analiza el `git diff` o los cambios preparados (staged).
- Muestra el mensaje final en el chat dentro de un bloque de código markdown para que el usuario pueda copiarlo manualmente.
- El mensaje de commit DEBE seguir estrictamente la especificación de Conventional Commits (por ejemplo: feat(scope): descripción).

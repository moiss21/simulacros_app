📖 Guía de Creación de Exámenes

0. ¿Cómo añadir nuevos exámenes?

Para que el sistema reconozca tus exámenes, sigue estos pasos:

  1. Carpeta local: Crea una carpeta en tu ordenador (ej: Mis Tests).
  2. Archivos JSON: Dentro, crea archivos con extensión .json.
  3. Carga: Selecciona esa carpeta en el menú principal para importar todo el contenido.

1. Diccionario de variables (Configuración)

Aquí tienes una explicación sencilla de qué hace cada ajuste en el examen:

Variable ¿Para qué sirve?
subjectColor (Opcional) Define el color de la asignatura en el menú y cabeceras. Usa códigos Hexadecimales (ej: #4169e1). Si no se pone, se usará el azul por defecto.
penaltyRate Es el "castigo" por fallar. Si pones 0.33, cada 3 fallos te quitan 1 acierto. Si pones 0, fallar no resta puntos.
examDurationMinutes El tiempo máximo del examen. Si pones 0, el reloj será infinito.
canChangeResponse Si es "true", puedes cambiar de opinión tras marcar. Si es "false", la primera que toques se queda bloqueada.
passingPercentage La nota para aprobar. Poner 50 significa que necesitas la mitad de los puntos para el "APTO".
totalQuestionsToDisplay Cuántas preguntas quieres que salgan de golpe. Útil si tienes 100 en el archivo pero solo quieres hacer 20 cada vez.
emptyAnswersCount Si es "true", dejar una pregunta en blanco también te restará puntos como si hubieras fallado.

🤖 Prompt Maestro para generar exámenes con IA

Copia y pega este texto íntegro en tu IA (ChatGPT, Claude...) para obtener el archivo listo:

Genera un archivo JSON para un examen basado en el siguiente temario: [PEGA AQUÍ TU TEMARIO o PREGUNTAS].

REGLAS CRÍTICAS:
1. 'generalExplanation' debe razonar la respuesta correcta usando las palabras clave de la misma de forma técnica.
2. 'subjectColor' es un campo opcional dentro de 'examProperties' para definir el color visual (ej: #8e24aa).
3. Es VITAL que el JSON final siga exactamente esta estructura de metadatos y nombrado:

{
  "examProperties": {
    "id": "nombre-asignatura-simulacro-1.json",
    "subjectName": "Nombre Asignatura",
    "subjectColor": "#4169e1",
    "examTitle": "Simulacro Examen de [Asignatura] - UD 1, 2 y 3",
    "examSummary": "Cubre sistemas de control, lógica y componentes...",
    "examConfig": {
      "penaltyRate": 0.33,
      "examDurationMinutes": 40,
      "canChangeResponse": true,
      "passingPercentage": 50,
      "totalQuestionsToDisplay": 40,
      "emptyAnswersCount": false
    }
  },
  "questions": [
    {
      "id": 1,
      "text": "¿Enunciado de la pregunta?",
      "type": "single",
      "generalExplanation": "Explicación detallada...",
      "options": [
        { "text": "Opción Correcta", "isCorrect": true, "explanation": "Incorrecto. ..." },
        { "text": "Opción Incorrecta", "isCorrect": false, "explanation": "Correcto. ..." }
      ]
    }
  ]
}

2. Notas importantes

  • ID y Archivo: El nombre que pongas en el campo "id" debe ser igual al nombre con el que guardes el archivo en Windows/Mac.
  • Colores: Si quieres usar los colores estándar del sistema, usa estos códigos: Sistemas de Potencia (#fbc02d), Documentación Técnica (#4169e1), Informática Industrial (#4db6ac), Sistemas de Medida (#8e24aa).
  • UTF-8: Al guardar el archivo, asegúrate de que la codificación sea UTF-8 para evitar errores con las tildes.

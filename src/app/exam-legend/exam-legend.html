📖 Guía de Creación de Exámenes

0. ¿Cómo añadir nuevos exámenes?

Para que el sistema reconozca tus exámenes, sigue estos pasos:

  1. Carpeta local: Crea una carpeta en tu ordenador (ej: Mis Tests).
  2. Archivos JSON: Dentro, crea archivos con extensión .json.
  3. Carga: Selecciona esa carpeta en el menú principal para importar todo el contenido.

1. Diccionario de variables (Configuración)

Ajustes disponibles dentro del objeto examConfig para personalizar el comportamiento del test:

Variable ¿Para qué sirve?
penaltyRate Es el "castigo" por fallar. Si pones 0.33, cada 3 fallos restan 1 acierto. Si pones 0, los fallos no restan.
examDurationMinutes Tiempo máximo en minutos. Si pones 0, el tiempo será ilimitado.
canChangeResponse Si es true, permite cambiar de opción. Si es false, la primera respuesta marcada queda bloqueada.
passingPercentage Porcentaje de aciertos netos para aprobar. Poner 50 significa que necesitas un 5.0 sobre 10 para el "APTO".
totalQuestionsToDisplay Número de preguntas que se mostrarán en el test. Si el JSON tiene 100 preguntas y pones 40, el sistema elegirá 40 al azar cada vez.
emptyAnswersCount Si es true, dejar una pregunta en blanco restará puntos igual que un fallo. Por defecto debe ser false.
groupByUnit [CRÍTICO] Si es true, el examen ordenará y agrupará las preguntas por bloques didácticos (Unidades). Si es false, se tratará como un bloque único o mezcla aleatoria global.

🤖 Prompt Maestro para generar exámenes con IA

Copia el bloque de texto inferior según la estructura que necesites y pégalo en tu IA de confianza:

📌 Elige el prompt adecuado según tu caso:

📋 Opción A: Examen estructurado POR UNIDADES (Recomendado para temarios largos)

Usa este prompt si quieres que las preguntas estén clasificadas por temas/unidades y el sistema las agrupe de forma ordenada.

Genera un archivo JSON para un examen basado en este temario/preguntas: [PEGA AQUÍ TU TEXTO].

REGLAS DE CONFIGURACIÓN Y FORMATO:
1. 'groupByUnit' DEBE SER true.
2. Cada pregunta DEBE incluir obligatoriamente el campo 'unit' (ej: "UD 1: Introducción", "UD 2: Planos") para que el sistema las agrupe correctamente.
3. 'generalExplanation' debe razonar técnicamente por qué la opción correcta es la verdadera.
4. Las explicaciones individuales de las opciones ('explanation') deben ser coherentes: si 'isCorrect' es true, su explicación justifica el acierto. Si es false, justifica el motivo del error.

ESTRUCTURA DEL JSON:
{
  "examProperties": {
    "id": "nombre-archivo-en-disco.json",
    "subjectName": "Nombre de la Asignatura",
    "subjectColor": "#4169e1",
    "examTitle": "Título del Examen (ej: Simulacro Global)",
    "examSummary": "Descripción breve del contenido del examen...",
    "examConfig": {
      "penaltyRate": 0.33,
      "examDurationMinutes": 90,
      "canChangeResponse": true,
      "passingPercentage": 50,
      "totalQuestionsToDisplay": 60,
      "emptyAnswersCount": false,
      "groupByUnit": true
    }
  },
  "questions": [
    {
      "id": 1,
      "unit": "UD 1: Nombre de la Unidad",
      "text": "¿Pregunta perteneciente a la Unidad 1?",
      "type": "single",
      "generalExplanation": "Explicación técnica global del concepto...",
      "options": [
        { "text": "Respuesta Correcta", "isCorrect": true, "explanation": "Correcto. Se cumple la normativa..." },
        { "text": "Respuesta Incorrecta", "isCorrect": false, "explanation": "Incorrecto. Este parámetro no aplica porque..." }
      ]
    }
  ]
}

📋 Opción B: Examen general SIN UNIDADES (Bloque único o Test Final)

Usa este prompt para exámenes rápidos, certificaciones o cuando los contenidos no requieran estar categorizados por temas separados.

Genera un archivo JSON para un examen basado en este temario/preguntas: [PEGA AQUÍ TU TEXTO].

REGLAS DE CONFIGURACIÓN Y FORMATO:
1. 'groupByUnit' DEBE SER false.
2. NO incluyas el campo 'unit' dentro de las preguntas.
3. 'generalExplanation' debe razonar técnicamente por qué la opción correcta es la verdadera.
4. Las explicaciones individuales de las opciones ('explanation') deben ser coherentes: si 'isCorrect' es true, su explicación justifica el acierto. Si es false, justifica el motivo del error.

ESTRUCTURA DEL JSON:
{
  "examProperties": {
    "id": "nombre-archivo-en-disco.json",
    "subjectName": "Nombre de la Asignatura",
    "subjectColor": "#8e24aa",
    "examTitle": "Título del Examen (ej: Test de Certificación)",
    "examSummary": "Evaluación directa sin distinción de bloques temáticos...",
    "examConfig": {
      "penaltyRate": 0.25,
      "examDurationMinutes": 30,
      "canChangeResponse": true,
      "passingPercentage": 70,
      "totalQuestionsToDisplay": 20,
      "emptyAnswersCount": false,
      "groupByUnit": false
    }
  },
  "questions": [
    {
      "id": 1,
      "text": "¿Pregunta de conocimiento general o bloque único?",
      "type": "single",
      "generalExplanation": "Explicación técnica de la solución...",
      "options": [
        { "text": "Respuesta Correcta", "isCorrect": true, "explanation": "Correcto. Esto es así debido a..." },
        { "text": "Respuesta Falsa", "isCorrect": false, "explanation": "Incorrecto. No confundir con..." }
      ]
    }
  ]
}

2. Notas importantes de consistencia

  • Coincidencia del ID: El valor de la propiedad "id" dentro de examProperties debe llamarse exactamente igual que el archivo físico guardado en el almacenamiento (ej: si el id es "test-potencia-1.json", el archivo debe llamarse test-potencia-1.json).
  • Lógica de Feedback: Asegúrate de que las IAs no inviertan el texto de las explicaciones. Las opciones válidas (isCorrect: true) deben llevar comentarios de felicitación o reafirmación, y las inválidas explicaciones del fallo.
  • Gama de Colores: Para mantener la armonía visual de la interfaz, puedes asignar colores personalizados a cada examen. Te recomendamos utilizar preferiblemente códigos Hex claros y visibles como estos:
    • Amarillo corporativo: #fbc02d
    • Azul estándar: #4169e1
    • Verde azulado: #4db6ac
    • Morado intenso: #8e24aa
  • Codificación de Archivo: Guarda siempre los archivos con codificación UTF-8 desde tu editor de texto (Notepad++, VS Code, etc.) para que los caracteres especiales, acentos y eñes se rendericen de forma nativa en la aplicación.
